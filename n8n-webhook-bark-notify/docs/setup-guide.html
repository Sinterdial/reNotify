  1. 打开 n8n 控制台，点击 Add Workflow 新建工作流；

8 常见问题与排错自检
发送请求返回 404 Not Found？

请确认已在 n8n 画布右上角开启 Active；如果使用的是 /webhook-test/ 测试入口，必须先点击画布下方的 Execute/Test workflow 按钮后才会在短时间内监听一次。

连续下载多集剧集没有合并，而是一集发一条？

请检查 n8n 容器环境变量是否已配置 NODE_FUNCTION_ALLOW_BUILTIN=fs 并重启容器；同时确认 入库缓冲 与 刷出入库缓冲 两个节点中的 BUFFER_DIR 一致且进程对其有写权限。

Bark 通知没有显示自定义图标？

Bark iOS 端要求图标 URL 必须能在手机当前网络下通过 HTTPS 直接访问（支持 PNG/JPG）。内网 IP 图标在手机切到蜂窝流量时无法加载，建议使用公网图床或 cdn.jsdelivr.net/gh/selfhst/icons/png/...。

返回 HTTP 400（无匹配通知）是报错吗？

不是异常。工作流对未知来源、与结构化事件重复的 MoviePilot 纯文本通知、以及仅记账字段变化的 subscribe.modified 会主动过滤并返回 400。而 120 秒内的重复通知会返回 HTTP 200（deduped: true）并静默拦截。
